# Android 安装包

本仓库只用于公开分发 Android APK。

## 下载

前往 [Releases](https://github.com/as7er/apex-gp-manager-releases/releases)，选择版本并下载 APK 附件。无需 GitHub 账号即可下载。

目前为 0.1.0 调试签名测试版。安装要求、验证范围、存档迁移及 SHA-256 校验值见对应发布说明。请在更新或卸载前导出存档。

注意：GitHub 自动生成的 Source code 压缩包仅包含此发布仓库的文件，不是游戏开发源码。APK 内的 JavaScript 与运行资源仍可能被解包提取。
